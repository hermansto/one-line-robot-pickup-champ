Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun — exactly one line, in a robot's voice.

> Beep boop — my circuits overheated the second you smiled, so I'm now running on love and one very tired cooling fan.

`main.ts` (Node 22, stdlib only) writes that single line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline, and reads it back to verify it matches byte-for-byte.
